## 交付内容

一个 `RModifier.exe`、一个主窗口，顶部切换掉落编辑、角色台词、地图编辑。地图页已接入原 Flash 编辑器的实际界面与原“预渲染”面板，并保留“随机房审查”扩展入口。三页切换保留各自的编辑内容；地图实例不会每次切页重启。

项目文件夹已由 **`LootEditor` 更名为 `RModifier`**，完整位置为 `D:/Program Files/Steam/steamapps/common/Remains/mods/RModifier`。不再建立旧目录。`LootEditorMod` 是既有游戏模块类名，继续沿用，旧备份文件名也保留。

0.2.0 的三编辑器整合、目录迁移及 ModLoader 接入见 [上一份整合报告](2026-09-28-rmodifier-integration-result.md)。本报告记录之后新增的原 Flash UI 需求。

## 如何使用

1. 双击项目顶层 `RModifier.exe`。旧版编辑器已在用户确认保存后正常关闭，正式入口已替换为新版。
2. 顶部选择“地图编辑”，使用原素材列表、画布和房间属性。
3. 原界面底部“预渲染”打开真实原预览面板。新底栏的“适应 / 100% / ＋ / －”控制显示大小；箭头平移，“原点”返回左上角。若预览工具栏在视野外，点“原点”或“适应”找回；按 Esc 返回编辑。也支持空格拖动、Ctrl+滚轮缩放。
4. 顶部“另存副本”保存完整地图 XML。保存或导出不会自动安装地图。原预览可导出 PNG。
5. 可以随时切回掉落或角色台词页。关闭时按页保存，或保留恢复草稿，下次继续。

EXE 可单独复制，启动时自动释放自带组件，不要求玩家安装 Node 或手动运行命令。仍需本机游戏素材；从游戏目录外运行时选择游戏文件夹。持续数据位于持久工程目录，不放在临时解压位置。

## 改动与保护

- 地图使用完整原文作为保存依据；只更新实际编辑的片段，保留未知字段、脚本、固定地图连接、BOM 与换行。未完成属性输入、撤销记录和预览位置可以恢复。
- 保存回执与当前文档、修订和内容指纹对应；对话框取消后恢复输入，过期保存结果不会误判新修改已保存。无法确认原界面输入时不直接关闭。
- 修复原界面在随机房间集合中点击“切换层”后触发空引用的问题。现在提示此操作只用于固定地图；固定地图的上下层切换仍可用。
- 本机 200% 系统缩放下已修正 AIR 逻辑坐标与 Windows 物理像素的重复放大。原窗口为主窗口拥有的无边框区域，无独立标题栏或任务栏入口，不置顶。
- 编辑器版本为 **0.3.0**；掉落运行模块及配置协议仍为 **0.2.0**。本轮不用重新改游戏补丁或 ModLoader 登记。

## 已知边界

原预渲染仍是静态场景，不运行实战 AI 或剧情；保留随机房路线信息不等于重新计算路线。原地图界面保留专业属性，复杂或无法可靠映射的 XML 会拒绝编辑以保留原文。

本机中文文本输入和 200% 缩放已实测，真实中文输入法候选组合、不同缩放显示器之间拖动仍未实测。没有宣称完成真人新手试用、长期平衡或所有地图功能穷举。

用户的正式游戏保持运行，按其决定留待自行重启；新游戏读取回执尚待实际重启核验。没有替用户应用掉落示例，也没有写入正式台词或地图。
